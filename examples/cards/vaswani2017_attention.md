## §1 One-liner

Replaces recurrence and convolution in a sequence-transduction encoder-decoder with multi-head self-attention alone, and reports better WMT 2014 translation at lower training cost.

## §2 Question

Whether a sequence model can be built from attention only — no recurrent layer, no convolutional layer — and still beat the recurrent/convolutional state of the art on translation quality and on training cost.

## §3 Prior work

[as-claimed] The paper positions itself against three families: recurrent encoder-decoders with attention (Bahdanau et al.), convolutional sequence models (ByteNet, ConvS2S), and the then-current WMT leaders including ensembles (GNMT + RL, MoE, Deep-Att + PosUnk). Its claim about them is quantitative and is reproduced in §5 below rather than paraphrased: the comparison is Table 2, and the numbers there are the only basis for "better".

Mechanism, in one paragraph: scaled dot-product attention `softmax(QK^T/sqrt(d_k))V`, run `h` times in parallel with learned projections and concatenated (p.4-5 §3.2); each sub-layer wrapped in residual + layer norm; position enters only through fixed sinusoids added to the input embeddings (p.6 §3.5); the feed-forward block is two linear layers with a ReLU between them (p.5 §3.3).

## §6 Limitations

### Author-stated

- Label smoothing "hurts perplexity ... but improves accuracy and BLEU score" (p.8 §5.4) — the authors report the cost of their own choice.
- Single-head attention is 0.9 BLEU worse than the 8-head setting (p.9 §6.2).
- Restricted (local) self-attention is left to future work (p.7 §4).
- The parsing result is "better than all previously reported models **with the exception of** the Recurrent Neural Network Grammar" (p.10 §6.3) — the authors name the model that beats them, 93.3 vs 92.7.

### Reader-observed

- **One internal contradiction, unresolved.** §6.1 (p.8) states the EN-FR big model "achieves a BLEU score of 41.0"; Table 2 on the same page, and the abstract on p.1, both print 41.8. The card records both locators and does not decide which is the paper's value.
- **The base-model claim has a narrower scope than it reads.** "Even our base model surpasses all previously published models and ensembles" sits inside the EN-DE paragraph and is true there (27.3 vs 26.36). Read as a claim about both directions it is false by the paper's own table: EN-FR base is 38.1 against a prior single model at 39.2.
- **Training cost is an estimate built on assumed hardware rates.** Footnote 5 fixes 2.8/3.7/6.0/9.5 TFLOPS per GPU; no measured wall-clock, utilization, or memory figure is reported for the FLOPs column, so the column is a model of the cost, not a record of it.
- **No uncertainty on any number.** Every table is a single run. The paper's comparative claims are therefore claims about point estimates.
- **The BLEU implementation is unspecified** (tokenisation, case, multi-reference), which matters because the margins against prior work are 1-2 BLEU.

## §7 Transferable

- **The one-component-at-a-time ablation on a dev set** (Table 3 rows A-E) is cheap to copy and produces a table a reader can audit: each row changes one axis, everything unlisted is identical to the base row. The caption says so explicitly, which is what makes the table readable.
- **Cost as a first-class column.** Reporting training FLOPs next to quality forces the "better at what price" question into the same table; the estimation recipe (time x GPUs x assumed TFLOPS) is reproducible and its inputs are stated.
- **Checkpoint averaging of the last k checkpoints** (5 for base, 20 for big) is a free gain worth testing in any training loop that already writes periodic checkpoints.
- **A per-wordpiece metric caveat in the caption.** The PPL column is explicitly marked as not comparable across tokenisations — the cheapest way to stop a downstream reader from making a wrong comparison.
