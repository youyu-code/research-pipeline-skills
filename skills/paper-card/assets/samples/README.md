# Sample fixtures

Everything in this folder is **synthetic**. No real paper, no real numbers, no real venue. The values were chosen to be obviously fake (Model A/B/C, "synthetic set A") so that nothing here can be mistaken for a record.

The fixtures exist for three reasons: the scripts need something to be tested against, a new user needs to see a filled card before producing one, and the pitfalls in `references/` need a reproducible shape rather than a story.

| File | What it is | Generated by |
|---|---|---|
| `synthetic_paper.pdf` | 4 pages: prose, an upright table, the same table rotated 90°, and a deliberately blank page | `make_sample_pdf.py` |
| `synthetic_si_tables.xlsx` | 2 sheets — `Hyperparameters` (4×3), `Datasets` (3×2) | `make_samples.py` |
| `synthetic_si_methods.docx` | 1 table (3×3) | `make_samples.py` |
| `demo2026_pipeline-selftest.md` | a filled card for the above, conformant to schema v1 | written by hand from the actual script output |

## Regenerate

```bash
python make_sample_pdf.py      # writes synthetic_paper.pdf
python make_samples.py         # writes the .xlsx and .docx
```

Both scripts use only the standard library plus `pymupdf` for the PDF. Re-run them after changing a script's output format; the expected numbers below are tied to the current fixtures.

## Expected output — self-test in five commands

```bash
python ../../scripts/pdf_text.py --pdf synthetic_paper.pdf --out /tmp/t1
python ../../scripts/pdf_text.py --pdf synthetic_paper.pdf --out /tmp/t2 --mode text
python ../../scripts/table_coords.py --pdf synthetic_paper.pdf --pages 2 --out /tmp/t3
python ../../scripts/rotated_table.py --pdf synthetic_paper.pdf --page 3 --out /tmp/t4
python ../../scripts/check_card.py demo2026_pipeline-selftest.md
```

| Step | Expected |
|---|---|
| `pdf_text` layout | `pages=4 chars=559 verdict=partly-empty`, suspect `[4]`, warning `Rotated text discovered` |
| `pdf_text` text | `pages=4 chars=448 verdict=partly-empty`, suspect `[4]` — same page, different extractor, still nothing |
| `table_coords` p.2 | `rows=5 cols=3`, header `Model / MSE / CI` |
| `rotated_table` p.3 | `rotated=12 rows=4 cols=3`, identical cells to page 2 |
| `check_card` | `PASS` with 9 values carrying provenance |

Four things this fixture is built to demonstrate:

- **A blank page and a failed page look identical in aggregate.** Page 4 returns nothing from both extractors; that agreement is what makes "blank" a conclusion rather than a guess. See `pitfalls-extraction.md` §01.
- **A rotated table survives.** Page 3 is the same data as page 2, rotated — `rotated_table.py` must reproduce it cell for cell. See §06.
- **Two independent rebuilds agreeing is the strongest check available** without the publisher's source. See the cross-check paragraph in `citation-rules.md`.
- **`check_card.py` fails loudly.** Its negative path is tested against a deliberately broken card; exit 3 prints one line per violation. If you want to see it, copy `demo2026_pipeline-selftest.md`, break one enum, and re-run.
