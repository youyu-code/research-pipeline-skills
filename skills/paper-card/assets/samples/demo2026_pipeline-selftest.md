## §6 Limitations

### Author-stated

The fixture states that it is synthetic and contains no real data.

### Reader-observed

- The SI reports a **different metric family** from the body: the body reports MSE per model, the SI reports a single AUC and one RMSE in `kcal/mol`. There is no per-model table in the SI, so the body's numbers cannot be independently checked against it.
- The single AUC value in the SI (0.881) equals the highest body `CI` value exactly (Model A, 0.881). This is either a coincidence of the fixture or evidence that `CI` in the body means AUC. **Not resolved here** — a card records the coincidence, it does not name the metric.
- `RMSE` in `kcal/mol` is a docking-energy unit, which does not belong to an MSE/AUC table. Its referent is unstated.

## §7 Transferable

- The pattern "body table per model + SI table per hyperparameter" leaves the headline numbers unverifiable no matter how complete the SI looks. Worth checking in real papers before assuming SI presence implies verifiability.
- Unit mismatch (a `kcal/mol` row in an accuracy table) is a cheap detector for a table pasted from another experiment.
